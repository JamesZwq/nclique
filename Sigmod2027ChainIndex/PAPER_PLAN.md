## Thesis (framing chosen by the user: partition first, not "store S trees")

Hierarchy equivalence (same core value at every size and same community at
every level) is a partition of the vertices into chains; every community is
a union of chains; an index over chains stores and retrieves each vertex
once. Aligned labels, lexicographic chain order, run arrays with entry
points and certified tails turn the partition into contiguous memory.

## Contributions (final deliverables only)

1. Theorem: chains = hierarchy equivalence (thm:chains); communities are
   unions of chains (lem:union); twins refine chains (lem:twins).
2. The index: aligned labels; size-2 communities are one range
   (thm:onerange); run arrays + entry points retrieve any community as the
   fewest ranges in O(1) after the climb (thm:retrieval); certified tail
   (thm:tail) removes most stored values.
3. Streaming construction: one all-size peel, one pass per size, memory
   linear beyond the peel's clique tree.
4. Evaluation on 29 graphs: 1.28x-48.7x smaller than one tree per size,
   median 7.0x; locate 4-76 ns; listing at memory-copy speed; brute-force
   verification on 34,075 graphs.
