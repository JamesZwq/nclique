\section{Conclusion}\label{sec:conclusion}
% 2026-09-21 house shape: the challenge nouns and the headline numbers verbatim; scope kept neutral.  Cadence pass.

In this paper, we presented \chainidx, an index for the clique-core hierarchies of every clique size at once.
% 2026-09-22 filler pass: the label sentence naming the three challenges removed.
%
The vertices no query can tell apart are exactly the chains, and chains are the coarsest lossless partition.
%
Aligned labels, a chain order and run arrays turn the partition into communities returned in constant time.
%
On \numgraphs{} graphs the index is \ratiomin$\times$ to \ratiomax$\times$ smaller than one hierarchy per size, median \ratiomedian$\times$.
%
It lists a community about as fast as a memory copy, and it is built for every size \priormin$\times$ to \priormax$\times$ faster than one decomposition per size.
%
Two case studies showed that the best size changes from query to query on DBLP and that the size narrows a community from a store to a shelf on Amazon.
