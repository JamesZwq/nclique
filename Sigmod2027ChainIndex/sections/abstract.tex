The $(1,s)$-nucleus decomposition assigns every vertex of a graph a core value for every clique size $s$.
%
It organizes the vertices of each size into a hierarchy of nested communities.
%
A community query names a vertex, a size and a level, and the size is chosen at query time.
%
Serving every size from a stored index has meant one hierarchy per size.
%
A vertex is then stored once for every size it lives in, and the index reaches hundreds of megabytes on graphs of a few hundred thousand vertices.
%
This paper stores each vertex once for all sizes.
%
Two vertices are hierarchy-equivalent when no value or community query at any size tells them apart.
%
We prove that this holds exactly when, at every size, the two vertices share the smallest community containing them.
%
The classes, called chains, partition the vertices and form the coarsest partition an exact index can use.
%
We propose \chainidx, an index over chains.
%
Aligned labels make every chain one interval of ids and every community a list of ranges.
%
A chain order makes every size-$2$ community one range, and per-size run arrays with entry points return any community as the fewest ranges in constant time.
%
Core values are stored only below the size at which they reach a closed form.
%
The index of every size is built from one clique tree, and each size reuses the removal order of the previous size when a check on clique counts proves the reuse exact.
%
On \numgraphs{} graphs from five families, \chainidx is \ratiomin$\times$ to \ratiomax$\times$ smaller than one hierarchy per size (median \ratiomedian$\times$).
%
It locates a community in \locmin{} to \locmax{} nanoseconds and lists it at the speed of a memory copy.
%
It is built for every size \priormin$\times$ to \priormax$\times$ faster than one decomposition per size.
%
Two case studies on graphs whose vertices carry names and categories show what the size buys.
%
On DBLP the best size changes from query to query.
%
On Amazon the size narrows a community from a store of $157{,}331$ products to a shelf of six albums.
