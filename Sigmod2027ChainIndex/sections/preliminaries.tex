\stitle{Graphs and cliques.}
% 2026-09-22 prose pass: words before symbols; the clique-number example says why.
We consider a simple undirected graph $G$ with vertex set $V$ and $n$ vertices.
%
An \textit{$s$-clique} is a set of $s$ pairwise adjacent vertices.
%
A $2$-clique is an edge, and a $3$-clique is a triangle.
%
The \textit{clique number} of a vertex $v$, denoted as $\omg{v}$, is the largest size of a clique containing $v$.
%
A subset of a clique is a clique, so $v$ lies in an $s$-clique for every size $s$ from $2$ to $\omg{v}$ and for no larger size.
%
In Figure~\ref{fig:example}, the clique number of $a_1$ is $5$, since $A$ has five vertices.
%
The clique number of $x$ is $4$ because of $B$.
%
That of $u_1$ is $3$: it lies in the triangles $\{x,u_1,w_j\}$ for $j=1,2,3$ and in no $4$-clique, since no two of $u_1,u_2,u_3$ are adjacent.

\stitle{Clique cores.}
% 2026-09-22 the model is named the clique core (the k-core with cliques of s vertices in place of edges); the nucleus
% name is given once as the origin.  Cold-read fixes: maximal glossed, the connectivity property named.
The community model of this paper is the $k$-core with cliques of $s$ vertices in place of edges, which we call the \textit{clique core} at clique size $s$ and level $k$ and write $\Nuc{s}{k}$.
\begin{definition}[$(s,k)$-core]\label{def:nucleus}
For a clique size $s\ge2$ and a level $k\ge1$, an $\Nuc{s}{k}$ is a set $N\subseteq V$ with two properties, to which no vertex can be added without losing one of them.
%
Every vertex of $N$ lies in at least $k$ cliques of $s$ vertices contained in $N$.
%
Any two vertices of $N$ are joined by a sequence of $s$-cliques contained in $N$: the first clique contains one of the two vertices, the last contains the other, and consecutive cliques share a vertex.
%
We say that $N$ is connected through its $s$-cliques.
\end{definition}
% the origin of the model, named once
An $\Nuc{s}{k}$ is a $k$-$(1,s)$-nucleus in the terminology of Sariy\"uce et al.~\cite{firstNucleus}, the vertex case of their $(r,s)$-nucleus, and the $(1,s)$-nucleus decomposition computes the core values of one size.
%
We keep the name core and the vertex as the unit throughout.
%
For $s=2$ the cliques are edges, and a $(2,k)$-core is a connected $k$-core: a maximal connected subgraph in which every vertex has at least $k$ neighbours.
%
Two cores of the same size $s$ and level $k$ are disjoint.
%
If they shared a vertex, their union would have both properties, the two clique sequences being joined at the shared vertex, so each of them could be extended.
%
The \textit{core value} of $v$ at size $s$, denoted as $\core{s}{v}$, is the largest $k$ such that $v$ belongs to an $\Nuc{s}{k}$.
%
% 2026-09-22 cold read (Sections 3/4): the converse stated once here, Section 3 and the proofs lean on it.
It is $0$ if $v$ lies in no $s$-clique, and at least $1$ otherwise, since an $s$-clique containing $v$ has the two properties at level $1$ and extends to an $\Nuc{s}{1}$.
%
The \textit{community} of $v$ at $(s,k)$, for $1\le k\le\core{s}{v}$, is the $\Nuc{s}{k}$ containing $v$.
%
Such a core exists.
%
The $\Nuc{s}{\core{s}{v}}$ containing $v$ has the two properties at level $k$ as well, since $k\le\core{s}{v}$, and adding vertices to it until neither property can be kept gives an $\Nuc{s}{k}$ containing $v$.
%
This core is unique, since cores of one size and level are disjoint.
\begin{example}\label{ex:nucleus}
% 2026-09-22 compaction: eight sentences; every count is from make_concept.py (kappa_3 = 6 on A, 3 on N; kappa_2 = 4 on A and {x,u,w}, 3 on b_i; kappa_4 = 4 on A, 1 on B; kappa_5 = 1 on A).
Consider Figure~\ref{fig:example} at size $3$, writing $\{u_1,\dots,w_3\}$ for the six vertices $u_1,u_2,u_3,w_1,w_2,w_3$ as in Example~\ref{ex:intro}.
%
Each $a_i$ lies in $\binom{4}{2}=6$ triangles, all inside $A$ since the edge $a_5b_3$ lies in none, so $A$ is a $(3,6)$-core and $\core{3}{a_i}=6$.
%
Each $b_i$ lies in the three triangles of $B$, each $u_i$ and each $w_j$ in the three triangles $\{u_i,w_j,x\}$, and $x$ in twelve.
%
The set $N=B\cup\{u_1,\dots,w_3\}$ is a $(3,3)$-core: every vertex lies in at least three of its triangles, every triangle of $N$ except $\{b_1,b_2,b_3\}$ contains $x$ and that one shares $b_1$ with $\{x,b_1,b_2\}$, and no vertex of $A$ can be added.
%
No vertex of $N$ has core value $4$: a $(3,4)$-core contains none of $u_1,\dots,w_3$, and without them a vertex of $B$ lies in three triangles only.
%
So $\core{3}{v}=3$ on $N$.
%
At size $2$, $\core{2}{v}=4$ on $A$ and on $\{x,u_1,\dots,w_3\}$ and $\core{2}{b_i}=3$: every vertex has at least three neighbours, no vertex but $x$ has five, so no $5$-core exists, and once $b_1$ and $b_2$, of degree three, are removed, $b_3$ keeps two.
%
At size $4$, $\core{4}{a_i}=\binom{4}{3}=4$ and $\core{4}{v}=1$ on $B$; at size $5$, $\core{5}{a_i}=1$.
\end{example}

\stitle{Queries.}
An index for this problem answers two queries, for every size $s$.
%
A \textit{value query} $(v,s)$ returns $\core{s}{v}$.
%
A \textit{community query} $(v,s,k)$ with $1\le k\le\core{s}{v}$ returns the vertex set of the community of $v$ at $(s,k)$.
% 2026-09-22 filler pass: three sentences on queries the index does not define (membership, the list of levels) removed.

\stitle{Problem statement.}
Given a graph $G$, we aim to build an index that answers value and community queries for every clique size $s\ge2$.
%
The index should store each vertex once and return every community as a few ranges of consecutive vertex ids.
