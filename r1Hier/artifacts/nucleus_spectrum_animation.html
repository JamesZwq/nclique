Nucleus Spectrum Index

r=1 vertex-nucleus 跨 s 索引 — 全部数字由 Python 直接 peeling 算出,真实数据(玩具图 + Zachary 空手道俱乐部)

要解决什么

κ_s(v) = 最大的 k,使得存在 v 所在子图 H,H 中每个顶点都参与 ≥ k 个 s-clique。s=2 是经典 k-core,s=3 是三角形 core,以此类推。每个 s 给出一棵 hierarchy 树 T_s。

目标:一份索引,对任意 s ∈ [2, ω] 返回完整 T_s 和 κ_s

本质是把 ω 棵分开的树压成一个共享结构。压缩有两层:① 轨迹压缩(anchor+delta,基于 Kruskal–Katona 律),② 区域去重(同一顶点集合在多个 s 复用)。下面用真实数据逐层讲。

定理 1 — Shifted Containment Law(Kruskal–Katona)

Cs+1k ⊆ Cs∂ₛ(k)　即逐顶点　κ_s(v) ≥ ∂ₛ( κ_{s+1}(v) )

∂ₛ(k) 是 k 的 Kruskal–Katona lower shadow:把 k 写成 s-cascade,取下影。直觉:v 有 ≥k 个 (s+1)-clique ⇒ 邻域里有 ≥k 个 s-clique ⇒ 由 KK 至少有 ∂ₛ(k) 个 (s-1)-clique ⇒ 每个配上 v 就是一个 s-clique。

这里修正了一个早先的错误: 曾用 g = C(d*, s−1)(d* = min{d : C(d,s) ≥ k}),它高估、无效,只在 k 恰为 C(d,s) 时才对。反例 s=3:κ₄=2 时真值 κ₃≥5,但该式给 6。暴力枚举(~76 万次 check)确认:KK shadow 才是有效且最紧的界(∂ₛ(k)+1 就失败)。

定理 2 + Anchor/Delta 编码(真正的压缩)

定理 2(支撑嵌套,已验证): {v : κs+1(v) > 0} ⊆ {v : κ_s(v) > 0}。所以 s*(v) = max{s : κ_s(v) > 0} 良定义,v 对所有 s ≤ s* 都存在 —— 这让"从 anchor 往下递推"合法。

编码方式

  • Anchor:(s*, κ_{s*}) —— 两个数
  • Deltas:δ_s = κ_s − ∂ₛ(κ_{s+1}) ≥ 0,从 anchor 往下重建 κ_s = ∂ₛ(κ_{s+1}) + δ_s
  • 饱和顶点 = 所有 δ=0 = 轨迹正好贴 KK 下界(邻域"像完全图")

逐顶点重建演示(空手道俱乐部真实数据)

选顶点:
饱和顶点(δ 全 0)只存 anchor 两个数,整条轨迹由 KK 公式推出;非饱和顶点额外存少数 δ。这是把 n×ω 的 κ 矩阵压成 O(n + 非零δ) 的来源。

Unified Region DAG 与诚实的压缩数字

把所有 T_s 的节点按顶点集合(region)去重,同一 region 在多个 s 复用,只存一份 + per-s 标注。注意身份用 region 而非 (region, kbirth) —— 后者因 kbirth 跨 s 必不同而几乎无法去重。

索引的几个数组

  • REGION_CSR / REGION_PTR — 每个 distinct region 的顶点集(去重后)
  • ANCHOR[v], DELTA[v] — 轨迹压缩(主压缩来源)
  • APPEARS[region] — 该 region 在哪些 (s, kbirth, parent) 出现
  • ROOTS[s] — T_s 的根 region 列表

维度诚实陈述
SpaceO(n + #δ + |V*| + Σ|T_s|)。没有 Ω(nω) 信息论下界(K_ω+孤立点塌成 O(ω))。压缩率数据依赖。
Query物化时 O(|T_s|),output-optimal;lazy 重建有隐藏项。
BuildO(ω·M)(bucket queue 去掉 log)。"必须 ω 次独立 peel" 不是定理;支撑嵌套(定理2)让 peel 可剪枝。
撤回的 3 个 overclaim:① 空间 Ω(nω) 下界;② build 必须 ω 次独立 peel;③ 跨 s pair query 的渐进胜(实为平局)。真胜场:存储 + 输出 o(Σ|T_s|) 的全局聚合查询(count-distinct region、present-in-all-s、stability)。

  2. 沿 per-s parent 指针遍历(从 APPEARS 标注取该 s 的 parent / kbirth)
  3. 每个 region 的顶点从 REGION_CSR 展开;kbirth 也可从 anchor+delta 用 ∂ₛ 现场派生
